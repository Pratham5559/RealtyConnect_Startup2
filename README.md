# RealtyConnect — SM-REIT Investment Platform

India's first Tier 2-focused, Hindi-first, IoT-powered SM-REIT fractional commercial real estate investment platform — regulated under SEBI's SM-REIT Regulations 2024.

## Stack
- React 18 + Vite
- React Router v6
- Tailwind CSS
- Lucide React icons

## Local development

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at vercel.com
3. Framework: Vite — auto-detected
4. Deploy

## Pages
- `/` — Waitlist landing page (Hindi/English)
- `/app/dashboard` — Portfolio overview + IoT building health
- `/app/properties` — All properties with filter
- `/app/properties/:id` — Property detail (4 tabs: overview, financials, documents, IoT)
- `/app/portfolio` — Holdings + distribution history
- `/app/secondary` — Live order book

## Legal disclaimer
This is a prototype. No real money is accepted. Minimum investment under SEBI SM-REIT Regulations 2024 is ₹10,00,000.
